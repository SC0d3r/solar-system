# Solar System Simulator Mini Game

An interactive solar system simulation with real orbital mechanics, planet inspection, and a lander mini-game. Built as a single HTML file — just for fun!

## Features

- Real orbital mechanics with Keplerian orbits
- Click any planet or the Sun to inspect details
- Scroll to zoom, drag to pan
- Lander mini-game on terrestrial planets (Mercury, Venus, Earth, Mars)
- Animated planet detail panels with stats
- Starfield background with twinkling effect

## Play Online

**[Play Now](https://SC0d3r.github.io/solar-system/)**

## How to Host on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose `main` branch and `/ (root)` folder
5. Click **Save**
6. Your site will be live at `https://SC0d3r.github.io/solar-system/`

> Rename `solar-system.html` to `index.html` before deploying so it loads automatically.

## Controls

| Action | Input |
|--------|-------|
| Pan | Click + Drag |
| Zoom | Scroll wheel |
| Inspect planet | Click on it |
| Lander thrust | W / Arrow Up |
| Lander rotate | A/D or Left/Right arrows |
| Exit lander | EXIT button |

## Tech

Single-file HTML/CSS/JS. No dependencies, no build step.
